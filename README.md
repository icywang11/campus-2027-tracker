# 王怡晨 2027 届校招投递台账

给 2027 届（山东大学日语笔译硕士）整理的中大厂校招数据页。岗位按简历筛选：海外运营、游戏社区、内容运营、跨境/国际化。

个人主页：[icywang11.github.io/portfolio-archive](https://icywang11.github.io/portfolio-archive/)

## 页面里有什么

- 行业、适配岗位、JD 摘要、投递链接、工作地点
- 每条岗位可勾选进度：未投递 / 投递中 / 测评中 / 笔试中 / 面试中 / 等结果 / 已拿 Offer / 已拒绝 / 已放弃
- 额外多选标记：已内推、材料已备、需跟进、优先冲
- 备注写在本机浏览器里，可导出 / 导入 JSON

岗位信息来自 2026 年 8–9 月各公司公开校招公告。HC 和完整 JD 以官网实时更新为准。

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43217](http://127.0.0.1:43217)。

生产构建：

```bash
npm run build
npm start
```
